# AS Collection

AS Collection is a database-backed Pakistani women’s fashion storefront built with Next.js App Router, React, TypeScript, PostgreSQL, and Prisma ORM.

## Start here

Read [SETUP.md](./SETUP.md) for Windows and VS Code setup, PostgreSQL, administrator creation, catalog management, custom stitching, COD and delivery settings, promotion configuration, Cloudinary uploads, WhatsApp click-to-chat, and deployment.

## Project status

- **Implemented in code:** responsive storefront, database-backed catalog, wishlist/cart, custom-measurement validation, retail/wholesale pricing, COD checkout, Safepay hosted card checkout flow, server-side payment confirmation, signed webhook verification, and a 5% discount for card payments only. COD has no card discount.
- **Still needs merchant setup:** Safepay sandbox/live API credentials, webhook secret and public HTTPS webhook endpoint, real products and photos, store policies/contact details, and Cloudinary credentials.
- **Not implemented:** customer accounts, newsletter, customer review workflows, and automatic WhatsApp Business notifications.

No sample product inventory is seeded. Add the store’s real catalog from `/admin` after setup.
